# Customer Churn Analysis Dashboard

An interactive Excel dashboard that analyzes why customers leave (churn) and which customer groups are most at risk.

## Key Metrics
| Metric | Value |
|---|---|
| Total Customers | 5,986 |
| Churned Customers | 1,587 |
| Churn Rate | 27% |
| Active Customers | 4,399 |
| Avg. Monthly Charges | 65 |
| Avg. Tenure | 33 months |

## Visualizations
- **Contract-wise Churn:** month-to-month vs one-year vs two-year contracts
- **Internet Service-wise Churn:** DSL vs Fiber optic vs no internet
- **Payment Method-wise Churn:** mailed check, electronic check, credit card, bank transfer
- **Churn Yes vs No:** overall split of churned and active customers
- **Tech Support-wise Churn:** churn with and without tech support
- **Paperless Billing by Churn:** how billing type relates to churn
- **Churn by Online Security:** churn with and without online security

## Interactive Filters (Slicers)
Contract, Gender, Internet Service, and Payment Method. Use these to explore churn for specific customer segments.

## Tools Used
- Microsoft Excel (Pivot Tables, Pivot Charts, Slicers, KPI cards)

## Purpose
To help businesses understand churn patterns and identify the customer segments that need retention strategies.
